# 가상메모리

<p align="center">
  <img src="../../Images/Computer-Science/memory-structure/Virtual-Memory.png" alt="Virtual-Memory" width="720" />
</p>

> 가상 메모리는 운영체제가 각 프로그램마다 독립적인 메모리 공간(가상 주소 공간)을 제공하는 기술이다.
>
> 프로그램이 사용하는 가상 주소는 실제 물리 메모리(RAM) 주소와 다르며, 운영체제가 이를 페이지 테이블을 통해 물리 주소로 변환해준다.
>
> 여러 프로그램이 동시에 실행돼도 서로 간섭하지 않고, 실제 메모리가 부족하면 보조기억장치 등을 활용하여 데이터를 저장(스왑)하고 불러올 수 있다.
>
> TLB라는 캐시를 사용해 주소 변환 속도를 높이고, 페이지 테이블을 여러 단계로 나누어 테이블의 크기가 너무 커지는 것을 방지하고 효율적으로 관리한다.

---

> [!NOTE]
> **보충**
>
> 페이지 테이블 + TLB는 Intel SDM Volume 3 (System Programming Guide)의 paging 설명이 원문이다.
> 가상 주소 -> 물리 주소 변환, TLB miss면 페이지 테이블 워크, 없으면 page fault.
>
> 다중 단계 페이지 테이블(x86-64는 보통 4레벨)은 희소 주소 공간에서 테이블 전체를 한 덩어리로 안 만들기 위해서다.

---

> [!WARNING]
> **더 보충이 필요한 부분**
>
> page fault가 났을 때 OS가 하는 일(요구 페이징, 스왑 인, SIGSEGV)은 정리에 한 줄로만 있다.
> Windows의 워킹 셋, 리눅스의 demand paging을 구분해서 말하려면 각 OS 문서를 봐야 한다.
> 이유는 "가상메모리 = 디스크에 다 내린다"로 오해하기 쉬워서다. 실제론 페이지 단위로 필요할 때 올린다.
