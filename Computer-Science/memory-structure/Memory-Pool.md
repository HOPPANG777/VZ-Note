# 메모리 풀

<p align="center">
  <img src="../../Images/Computer-Science/memory-structure/Memory-Pool.png" alt="Memory-Pool" width="720" />
</p>

> 메모리 풀은 미리 큰 메모리를 확보해 작은 블록 단위로 관리하는 기법이다. 빠른 할당·해제와 단편화 감소에 유리해서 게임이나 네트워크 서버에서 자주 쓴다.

필요한 메모리 공간이랑 크기, 개수 등을 프로그래머가 직접 지정해서 미리 할당 받아놓은 뒤
필요할 때마다 사용하고 다시 반납하는 구조다. 오브젝트 풀 생각하면 이해하기가 쉽다.
만들어놓고 안 쓰면 그 공간은 그냥 논다.

new/malloc을 매번 안 나가니까 빠르고, 같은 크기 블록만 다루면 외부 단편화도 덜하다.
대신 블록 크기보다 큰 객체는 못 넣거나 다른 풀이 필요하다.

---

> [!WARNING]
> **더 보충이 필요한 부분**
>
> 구현(free list, bitmap, 정렬된 크기 클래스)은 정리에 없다.
> 면접에서 "어떻게 만들었냐"가 나오면 이 그림이 필요하다.
> 표준은 없어서 구현 문서나 직접 코드를 보고 적어야 한다.
> C++로 풀 위에 객체를 올리려면 placement new가 필요하다. Malloc-Free.md에 적어 둔 이유다.
