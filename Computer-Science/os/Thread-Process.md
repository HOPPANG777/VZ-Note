# 스레드 / 프로세스

<p align="center">
  <img src="../../Images/Computer-Science/os/Thread-Process.png" alt="Thread-Process" width="720" />
</p>

> 스레드와 프로세스는 운영체제에서 작업을 처리하는 기본 단위다.
>
> 프로세스는 실행 중인 프로그램으로, 독립된 메모리 공간을 가지며, 각 프로세스는 다른 프로세스와 메모리를 공유하지 않는다.
>
> 반면, 스레드는 프로세스 내에서 실행되는 작은 작업 단위로, 같은 프로세스의 자원을 공유하여 작업을 수행한다.
>
> 이 때문에 스레드는 메모리 사용 효율이 좋고 빠른 전환이 가능하지만, 동기화 문제가 발생할 수 있다.
>
> 프로세스는 독립적 작업을, 스레드는 병렬 처리가 필요한 작업에 사용된다.

멀티 스레딩은 여러 스레드를 동시에 실행해 성능과 응답성을 높이지만 동기화 문제와 전환 비용 같은 단점도 있다.
