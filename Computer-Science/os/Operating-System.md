# 운영체제

<p align="center">
  <img src="../../Images/Computer-Science/os/Operating-System.png" alt="Operating-System" width="720" />
</p>

> 운영체제(OS, Operating System)는 컴퓨터 하드웨어와 응용 프로그램(사용자 프로그램) 사이에서 중간 매개체 역할을 하는 소프트웨어다.
>
> 하드웨어 자원(메모리, CPU, 저장장치, I/O 등)을 효율적으로 관리하고, 여러 프로그램이 동시에 안전하게 실행될 수 있도록 프로세스 관리, 메모리 관리, 파일 시스템 관리, 입출력 관리 등의 핵심 기능을 제공한다.
