# Spatial Hash (공간 해시)

<p align="center">
  <img src="../../Images/Computer-Science/data-structure/Spatial-Hash.png" alt="Spatial-Hash" width="720" />
</p>

> 오브젝트를 격자 셀 해시에 넣고 같은 셀(+인접 셀)끼리만 좁은 단계 충돌 검사를 한다. cellSize를 오브젝트 크기 수준으로 맞추면 후보 수가 급감해 O(N)에 가깝게 스케일된다.

오브젝트를 격자 셀에 넣고 해당 격자 셀 별로 충돌 처리를 해서 최적화하는 기법이다.
격자를 오브젝트 크기 수준으로 설정한다면 후보 수가 급감하여 최적화에 유리해진다.

Grid랑 Quad-tree를 비교하라는 질문이 있었다.
Grid는 정적 환경에서 단순하고, Quad-tree는 객체 밀도 변화에 적응적이다.
당시 프로젝트는 Grid로 충분해서 Quad-tree는 안 넣었다. 구현 난이도 대비 시간이 없어서다.
