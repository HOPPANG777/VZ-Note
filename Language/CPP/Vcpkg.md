# vcpkg

<p align="center">
  <img src="../../Images/Language/CPP/Vcpkg.png" alt="Vcpkg" width="720" />
</p>

> vcpkg는 C++ 패키지 매니저로, C++ 라이브러리들을 쉽게 설치, 관리하고 프로젝트에 통합할 수 있도록 돕는 도구다.
>
> 의존성 문제를 줄이고, 여러 플랫폼에서 같은 방식으로 패키지를 관리할 수 있다.

---

> [!NOTE]
> **보충**
>
> - **출처:** Microsoft 공식 문서 vcpkg (https://learn.microsoft.com/en-us/vcpkg/)
> Microsoft가 관리하는 C++ 라이브러리 매니저가 맞다.
> 표준 라이브러리가 아니라 도구다.
