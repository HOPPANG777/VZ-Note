# 포인터와 레퍼런스

<p align="center">
  <img src="../../Images/Language/CPP/Pointer-vs-Reference.png" alt="Pointer-vs-Reference" width="720" />
</p>

> 포인터는 변수의 주소를 저장하고 재할당이나 연산이 가능하며 nullptr도 될 수 있고, 레퍼런스는 변수의 별칭으로 반드시 초기화되며 변경할 수 없다.

상세는 Reference.md, Direct-Reference.md.
액세스 제한은 컴파일 타임이고 어셈블리에 락은 없다. Access-Modifier.md.
